# Commit Replay Bench

**Purpose.** Commit Replay Bench grades an AI builder against a repository's own held-out
tests, and delivers new change as branches and pull requests only in the cells that evidence
licenses (README; DL-044).

**Entry → exit.** A regulated organisation installs the signed image on its own
infrastructure with its own model keys, signs in, connects one repository, proves the
instrument on it for £0, and measures. It leaves with a capability map whose every cell
carries `n`, a Wilson 95% interval and the apparatus version, a route per class of change
(`deliver` / `calibrate` / `granularize` / `human`), a second person's signature on the cells
that clear the bar, and a pull request on its own repository that a human merges.

**Non-goals.** Not a leaderboard, not an AI's opinion of an AI's work, not a proof of
semantic correctness, not a licence to deploy. It does not merge anything itself, keeps
the redacted patch it graded (ADR-0006) but no transcript or worktree by default, does not
reach the public internet from a worker, and never moves code or identifiers between
tenants — only abstract cells.

## Gaps
- **G-653** — the north star has one reading, the baseline, and no paired campaign has measured it with the loop on · run the paired blind campaign on the same tasks with the loop off and on, then publish both readings with their intervals on the baseline page · factory
- **G-930** — the `dod`, `claims`, `ui-unit` and `ui-smoke` jobs run on every pull request but are not on branch protection's required-checks list (the README's status paragraph states this as a [measured] reading of the repository setting), so a type error, a missing hint, a wrong claim or a definition-of-done regression can still merge · an administrator adds the four checks to the required list, then re-evidence this criterion against the list rather than against the jobs' existence · deploy
- **G-605** — **[gap]** the definition-of-done artefacts make quantitative claims of their own (a journey's minutes and £, a page's counts, a stream's current state) and most of them carry no tags, so the rule the product applies to its own guides does not yet apply to the whole record of what done means (CodeRabbit on PR #47, again on PR #48). **The rule is decided and it is this:** a criterion's `criterion` cell is a *specification* and carries no tag and no measured metadata; prose outside the table — a purpose paragraph, a gap line, a wave row — carries a tag on every statement that quantifies something, and a `[measured]` one carries its n, its method and its apparatus version; a gap id and a typed evidence reference never carry a tag · apply that rule to the artefacts this wave did not reach, then write it into `docs/dod/STANDARD.md` §2 and gate it by putting `docs/dod/**` on `scripts/claims_check.py`'s ALLOWLIST · docs
- **G-600** — the identity sentence lives in the README only: no screen states what the product is (Home's About block describes the task list, not the product), and the long-form account of the product is not in this repository, so three readers get three different first sentences · put the README's first sentence verbatim in the `/home` About block and in `/help`'s index, and add a test that the three strings are one string · ui
