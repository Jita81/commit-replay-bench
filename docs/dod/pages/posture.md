# About this deployment (Deployment posture)

**Purpose.** A printable statement of how this deployment is built, secured and audited, for an architecture or security review. Each row is read from the running system or names its source (help.ts `/posture`).

**Entry → exit.** The person arrives from the nav link "Deployment" (`nav.posture`; step 3 of 4 of going live — the eyebrow reads "Run the platform · Deploy and go live · 3 of 4 · Deployment"), from Home's sandbox banner ("See the deployment's health") or from Home task 7 when they are not an admin. They read the go-live checklist's state — each line proven, attested or unproven, the product's own checks apart from the acts it does not perform — and five summary lists (build and apparatus, identity and access, execution and egress, delivery, data and audit — 24 rows **[measured — n = 24 rows across the five `groups` of `ui/src/screens/Posture/PosturePage.tsx`, method: by inspection on 2026-09-26, apparatus 2.3 — a count, so no interval]**). Every row whose value is not the production posture ends with the next step: a guide link for everyone and a "Settings" link for an admin. They leave with the statement (the About block says: print it, or send the URL) and, for an admin, the one-click path to Settings.

**Non-goals.** The page changes nothing: it has no form, and its one button prints it. It never shows a secret value, only whether one is configured. It is not the go-live checklist (DEPLOYMENT §8) and ticks nothing: it shows each line's state, and an operator's act is recorded on Settings, not here.
