# Run detail

**Purpose.** "One run: its progress, live log, per-task rows and their evidence packs. Cancel stops after the attempt in flight; nothing already graded is lost." (`help.ts`, About block; eyebrow `Runs · <repo> · <kind>`.)

**Entry → exit.** Arrive from a Runs row, the walk's "Open the run", the Measure page's in-flight banner, a repository's probe link, a Factory item, the Sign-off page's "Run" button or a task page's run column. Read the status pill, the Progress card (bar, queue position, the "Now" line with elapsed, spend and the estimate's basis, the stage from the last event, the worker heartbeat, a container being reaped), the headline tiles, the "Why not clean" split, the live log and the per-task table; open a row's evidence pack in the drawer (Pack, Patch and Review tabs). An operator presses "Cancel run" while the run is not terminal; the "cancel requested" pill replaces the button and the run ends `cancelled`. Leave by the nav or the repository link; task rows do not link to the task page.

**Non-goals.** Does not start or re-queue a run (Runs and the repository page do); does not edit or delete a row (the ledger is append-only, ADR-0002); does not show the capability map (Results and Map grid do); does not talk to the worker — cancel asks the API, which sets the flag the worker honours between tasks.
