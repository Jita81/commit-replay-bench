# Factory

**Purpose.** Deliver new work under the same rules as replay: a frozen backlog, a failing test proved before any build, a build inside the sandbox, and a branch and pull request only where the map routes deliver — every step on the evidence chain (`help.ts` About copy; eyebrow "Journey · 4 of 4 · Factory").

**Entry → exit.** Arrives from the nav, from Home task 8 ("Deliver your first change" / Continue while a factory run works an item), from a Decisions row with `?repo=&item=` (gap to sign, item routed to human, rework, delivery withheld), or from the repository's Next steps; with no `?repo=` the most recently updated repository is chosen, and with nothing connected the only exit is Connect. The person leaves with a frozen backlog (`frozen · hash · n items`), a queued factory run they can open at `/runs/:id`, and per item a six-step chain ending in a pull request link on the customer's repository or the sentence that says why delivery was withheld.

**Non-goals.** It does not take work from a ticket system: a backlog is typed into the freeze form or pasted as JSON. It is not a full run form — it runs the deployment's builder, or one an operator names, with no ladder, budget or executor knobs. It does not cap spend (it states an estimate, never a promise). It does not sign off a cell, change the map's route, review a diff, or merge the pull request it opens: the merge is a person's decision on the customer's repository.
