# Sign-off

**Purpose.** Record that a named approver reviewed a cell's evidence and read one accepted change. The server refuses a sign-off that does not meet the published policy; a refusal is the gate working, not an error (`help.ts` About copy; eyebrow "Journey · 3 of 4 · Decisions · sign-off").

**Entry → exit.** Arrives from Decisions "Attest" or the stale row's "Revoke or re-sign" (`/signoff?repo=&cell=`, the cell preselected), from the Baseline's "sign-off due" link, or by URL; with no `?repo=` the most recently updated repository is chosen; with no repository the only exit is Connect. The person leaves with a green "Sign-off recorded" panel and an `sgn_` reference, the row in the Attestations table, and links from the diff block to `/tasks/:repo/:taskId` and `/runs/:id`. The route is not in the nav: it is reached from the journey.

**Non-goals.** It does not change a cell's route, point or interval (a sign-off lifts the verification tier only). It does not vouch for any other class, size or repository. It never deletes a record: a revocation is a new row with a reason. It offers no "decline" action: declining is doing nothing, and the unsigned cell keeps its route. It does not create the approver's account (an admin does, in Settings) and it does not record the human review of a diff (that is the Review panel on `/runs/:id`).
