# Measure (sighted replay, blind, budget sweep)

**Purpose.** The operator buys the first rows on the map: a sighted replay in which a builder sees the failing test and the grader never trusts its word, priced before confirming, watchable and cancellable while it runs, every row carrying its belts, its failure kind and its cost. This is the only step in onboarding that spends money (Home task 5 of 8; ONBOARDING step 4). A viewer reads the run; nobody else spends.

**Entry → exit.** Arrive from Home task 5 "Measure — spends money" once stage 3 (mine, oracle, controls) is done. Leave with ledger rows for the repository (`process_step: replay`, `mode: sighted` or `blind`, the current apparatus), a run that ended `succeeded`, `failed` or `cancelled` with its reason on the page, and the Baseline showing the first cells at route `calibrate` until n ≥ 10. The optional blind budget sweep leaves rows stamped `labels.budget_tier` per rung.

**Non-goals.** Does not sign a cell (Sign off a cell does); does not read or route the map (Read the map and decide does); does not deliver (Manufacture does); does not run the £0 stages (Prove the instrument does); does not set a deployment or repository budget — only per-run caps exist, in the run dialog.
