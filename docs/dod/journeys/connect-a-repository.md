# Connect a repository

**Purpose.** A registered repository whose toolchain probe is green, so that a red test later
means the code and not the environment — stages 1 and 2 of the six on the walk, the
onboarding guide's Step 1 (register) and the shape that Step 2 will tune. The operator (a
developer) connects and probes; an admin registers the GitHub App once; a viewer reads the
walk. Nothing is written to the repository and no model is called.

**Entry → exit.** Enter from Home's task list (task 1 *Connect GitHub*, task 2 *Choose a
repository*, task 3 *Confirm its shape*) or from the nav (Connection). Leave with the walk on
`/connect/:name` reading *Repository registered* and *Toolchain probed* as Done, the probe pill
on the repository page reading OK with the runner's own summary, and stage 3 *Commits mined
into tasks* as the next Run (Home task 4 *Prove the instrument (£0)*).

**Non-goals.** Does not mine, score the oracle or run controls (Prove the instrument); does
not spend model budget (Measure); does not make the oracle reproducible across dependency
eras — that is Step 2's loop of mine → gold notes → configuration, which starts once tasks
exist; does not register the GitHub App (Deploy and go live).
