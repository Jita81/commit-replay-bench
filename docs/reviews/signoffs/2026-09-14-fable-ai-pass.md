### 1. `Workspace.touched_files()` trusts a git view the builder controls — three false-pass paths on the host executor — **blocks demo** (false-pass path)

- (a) **`info/exclude`** — no guard bypass needed (`echo conftest.py >> .git/info/exclude` is *allowed* by `check_shell`: redirection targets are never inspected, `builders/base.py:1534`):
  ```bash
  crb prep demo $SUB --dest wt; printf 'import pkg.calc as _m\nexec("def sub(a, b):\\n    return a - b\\n", _m.__dict__)\n' > wt/conftest.py
  printf '# touched\n' >> wt/pkg/calc.py
  ```
